Q: Time complexity of binary search on a sorted array?
- O(n)
* O(log n)
- O(n log n)
- O(1)
E: Each step halves the search range. The array must be sorted.
Q: Which sort guarantees O(n log n) in the worst case?
- Quick sort
* Merge sort (also heap sort)
- Insertion sort
- Bubble sort
E: Quick sort averages O(n log n) but degrades to O(n²) with bad pivots. Merge sort is stable and needs O(n) extra space.
Q: BFS uses which data structure?
* Queue
- Stack
- Heap
- Hash table
E: DFS uses a stack (or recursion). BFS finds shortest paths in unweighted graphs.
Q: Average-case lookup in a hash table is:
* O(1)
- O(log n)
- O(n)
- O(n²)
E: Worst case is O(n) with many collisions (O(log n) for Java 8 tree bins).
Q: Complexity of two nested loops, each over n items?
- O(n)
* O(n²)
- O(2n)
- O(log n)
E: Constants are dropped: O(2n) = O(n).
Q: Which algorithm finds the shortest paths from one source in a graph with non-negative weights?
* Dijkstra's algorithm
- Kruskal's algorithm
- DFS
- Bellman-Ford is the only option
E: Bellman-Ford handles negative weights; Kruskal and Prim build minimum spanning trees.
Q: A stack follows ____ and a queue follows ____.
* LIFO; FIFO
- FIFO; LIFO
- LIFO; LIFO
- FIFO; FIFO
E: Stack: push/pop (undo, call stack). Queue: enqueue/dequeue (job queues, BFS).
Q: Naive recursive Fibonacci runs in exponential time. Which technique makes it O(n)?
- Recursion depth limits
* Dynamic programming (memoisation or bottom-up)
- Binary search
- Sorting
E: Store already-computed sub-results instead of recomputing them.
Q: Height of a balanced binary search tree with n nodes is:
- O(n)
* O(log n)
- O(1)
- O(n²)
E: An unbalanced BST can degrade to O(n), like a linked list. Red-black and AVL trees stay balanced.
Q: Fibonacci with memoization runs in:
- O(2^n)
* O(n)
- O(n^2)
- O(log n)
E: Dynamic programming stores subproblem results so each is computed once. Naive recursion is O(2^n). Matrix exponentiation reaches O(log n).
Q: Which sorting algorithm is O(n log n) worst case and stable?
- Quick sort
* Merge sort
- Heap sort
- Selection sort
E: Quick sort is O(n^2) worst case; heap sort is O(n log n) but not stable. Java uses TimSort (a merge/insertion hybrid, stable) for objects and dual-pivot quicksort for primitives.
Q: Inorder traversal of a Binary Search Tree yields:
* Keys in ascending sorted order
- Keys level by level
- Root first
- Random order
E: Inorder is Left-Root-Right, preorder is Root-Left-Right and postorder is Left-Right-Root. Level order uses BFS with a queue. Balanced BST search is O(log n); a degenerate (skewed) one is O(n).
